# Student Marks Prediction using Machine Learning

## Project Description

This project predicts student marks using the Linear Regression algorithm.

The model is trained using:
- Study Hours
- Attendance
- Previous Marks

The output is:
- Predicted Student Marks

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm

Linear Regression

## Project Workflow

1. Import Required Libraries
2. Create Dataset
3. Data Exploration
4. Data Visualization
5. Feature Selection
6. Train-Test Split
7. Train the Linear Regression Model
8. Predict Student Marks
9. Evaluate Model Performance
10. Predict Marks for New Student Data
